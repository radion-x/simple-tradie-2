How to read this report

Visits include only visitors who allow analytics. All saved enquiries retain their available source, including those without analytics consent. Use the matched-visit figures for the visit conversion rate. Enquiries use email, or phone when email is absent, to group repeat requests. Exclude duplicates with different contact details. A transcript request alone is not an enquiry.

Paying customers require accepted scope and a cleared first payment. Record each business once using the same customer reference. Phone clicks are not confirmed calls. Add actual phone or Gumtree message enquiries below. Recorded sources describe the latest tagged visit; a source supplied by the customer is labelled separately.
